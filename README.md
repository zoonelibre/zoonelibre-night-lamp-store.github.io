# Zoonelibre — Night Lamp Store

A polished static ecommerce demo for **Zoonelibre**, focused on night lamps, bedside lighting, decorative lamps, portable lamps and smart RGB lighting.

## Highlights

- 20 real product references
- Multiple lamp styles and colors
- Retail reference prices checked September 29, 2026
- Live product-page previews for real-product imagery
- Search, category filter, color filter and price sorting
- Product quick-view modal
- LocalStorage shopping cart
- Customer support and lighting-advisory section
- FAQ, newsletter and responsive mobile design
- GitHub Pages friendly

## Important image note

Third-party product photography is not copied into this ZIP. Product cards use **live previews of the linked retailer product pages** via `image.thum.io`, so an internet connection is required to display those real-product previews. A local fallback graphic appears if the preview service is unavailable.

## Prices

The displayed values are **retail reference prices**, not guaranteed resale prices. Prices, discounts and availability can change. See `PRICE_SOURCES.md`.

## Demo contact details

The included `555` phone numbers are fictional demo numbers. Replace them with your real business support information before publishing.

## Run locally

Open `index.html` in a modern browser.

## GitHub Pages

1. Upload every file and folder to the repository root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.

## Before accepting real orders

Connect a payment provider, create legal policies, define shipping and return rules, confirm supplier/resale authorization, replace demo contact information, and verify current inventory/pricing.
