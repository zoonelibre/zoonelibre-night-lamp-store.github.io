# Zoonelibre — Night Lamp Store

A complete responsive night-lamp storefront for **Zoonelibre**.

## Final version includes
- 10 lamp product listings
- Dedicated lamp images stored locally inside the ZIP
- Different lamp styles and colors
- Verified U.S. retail reference prices
- Search and filters
- Shopping cart
- Support and lighting-advice section
- Responsive mobile design
- GitHub Pages ready

## Price verification
Prices were checked against U.S. retailer listings on **September 29, 2026**.
See `PRICE_SOURCES.md` for every reference and source URL.

## Product image note
The catalog images included in this ZIP are Zoonelibre product visuals created for the storefront.
They are not official retailer product photography, so the retailer name is shown only as the price reference.

## Before launching
Replace the demo 555 support numbers with your real business contact details and connect a real payment provider such as Stripe, PayPal or Shopify.

## Publish with GitHub Pages
Upload the contents of this ZIP to your repository root, then go to:

`Settings → Pages → Deploy from a branch → main → / (root)`
